# chatbot_rag_langchain
My first ChatBot with RAG under LangChain Framework

## The Idea Behind it
Since recently I became very much passionate about the latest AI technologies, in particular ML, Generative AI and I wanted to build something interesting, meaningful and at the same time to learn the Retrieval Augmented Generation (RAG) concept. 

This way I ended up with the course from Deeplearning.AI and LangChain (https://learn.deeplearning.ai/courses/langchain-chat-with-your-data/lesson/c1ngd/chat). I followed the course and built the chat along the way. The code is slightly modified from the one presented in the course to account for the latest updates.
